# qoder-open

面向真实开发场景的 agentic coding harness 开源实现。

本项目的接口形态、工具集与运行时机制，来自对 Qoder 桌面客户端（产品版本 0.4.3，构建于 2026-09-26 的 Windows x64 安装包）的静态分析。分析过程与结论全部记录在姊妹仓库 `qoder-re` 的 docs 目录中。

## 与上游的关系

本项目不是 Qoder 的官方项目，也未获得其授权。仓库中不包含任何原厂代码、原厂二进制、私钥或令牌。实现对下列已被公开记录的协议与机制做了独立重写：模型会话协议（gRPC `ChatService`，含流式与前缀缓存补丁）、工具调用协议、上下文压缩、权限判定、记忆与技能系统。

原厂产品的商标与版权归其所有者所有。使用者需自行遵守其所在地区法律与上游服务条款。

## 当前状态

实现按阶段推进。已完成骨架与基础工具，正在补齐 agent 主循环与模型适配层。

第一阶段包含：CLI 入口与参数解析、会话与消息模型、模型适配层（OpenAI 兼容与 Anthropic 兼容两种协议）、工具注册表与基础工具（读、写、编辑、命令执行、文件匹配、内容检索、待办列表）、以及运行时的权限判定。

第二阶段计划：后端会话协议对接（gRPC 流式）、上下文自动压缩、任务与子代理调度、记忆系统（当日记忆、记忆复核、记忆整理）、技能加载与 MCP 接入、以及交互式终端界面。

## 设计基线

工具集沿用被广泛验证的形态：读文件、写文件、编辑文件、执行命令、文件名匹配、内容检索、网络抓取、网络检索、待办列表、子任务、记忆、技能。工具的参数 schema 由实现自行定义，保持与主流模型协议兼容。

运行时为回合制：每回合把系统提示、历史消息与工具结果组装为一次请求，流式接收模型输出，解析其中的工具调用，按权限策略执行，将结果回填后进入下一回合，直到模型给出终态或触发终止条件。

上下文管理采用分级策略：接近阈值时先做工具结果的裁剪，再做摘要压缩；压缩是一次独立模型请求，失败按类别上报而不静默丢弃。

权限判定对每次工具调用给出允许、拒绝或需要确认，并带约束说明与理由，可配置为跳过确认以满足非交互场景。

## 快速开始

```bash
npm install
npm run build
node dist/index.js --help
```

开发模式直接运行 TypeScript：

```bash
npm run dev -- --help
```

配置模型端点与密钥通过环境变量或工作区配置文件提供，详见 `docs/configuration.md`（待补充）。

## 目录结构

```
src/
  index.ts            命令行入口
  cli/                参数解析与交互
  model/              模型适配层（协议、流式解析、用量统计）
  tools/              工具接口、注册表与各工具实现
  agent/              回合循环、上下文管理、权限策略
  memory/             持久记忆与检索
  session/            会话与任务状态
  config/             配置模型
```
